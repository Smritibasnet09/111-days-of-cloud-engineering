# AWS Important Topics

---

# 1. Amazon Redshift

Amazon Redshift is AWS data warehouse service used for big data analytics.

### Important Points
- Used for data analysis and reporting.
- Column-based storage.
- Very fast query performance.
- Works with SQL.

### Best For
- Business Intelligence (BI)
- Analytics
- Large datasets

### Exam Tip
Redshift = Data Warehouse + Analytics

---

# 2. AWS Glue

AWS Glue is a serverless ETL service.

### ETL Meaning
Extract → Transform → Load

### Uses
- Clean data
- Convert data
- Move data between services

### Important Feature
- Glue Data Catalog

### Exam Tip
Glue = Data preparation service

# 3. Amazon Athena

Athena allows SQL queries directly on S3 data.

### Features
- Serverless
- No database setup
- Pay per query

### Exam Tip
Athena = Query S3 using SQL
