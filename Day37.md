# AWS Learning Topics ☁️

## 1. Amazon EC2 (Elastic Compute Cloud)

### Description
Amazon EC2 is a service that lets you create virtual servers in the cloud.  
It helps developers run applications without buying physical computers.

### Example
A company hosts its website on an EC2 instance so users can access it online 24/7.

---

## 2. Amazon S3 (Simple Storage Service)

### Description
Amazon S3 is used to store files such as images, videos, backups, and documents securely in the cloud.

### Example
A mobile app stores user profile pictures in an S3 bucket.

---

## 3. AWS Lambda

### Description
AWS Lambda allows you to run code without managing servers.  
It automatically runs your code when an event happens.

### Example
When a file is uploaded to S3, Lambda automatically resizes the image.

---

## 4. Amazon RDS (Relational Database Service)

### Description
Amazon RDS helps users create and manage databases easily in the cloud.

### Example
An online shopping website uses MySQL on RDS to store customer orders and product details.

---

## 5. IAM (Identity and Access Management)

### Description
IAM is used to control who can access AWS resources and what actions they can perform.

### Example
An admin gives developers access only to EC2 services but blocks access to billing information.

---

## 6. Amazon CloudFront

### Description
CloudFront is a Content Delivery Network (CDN) that delivers content faster to users worldwide.

### Example
A video streaming website uses CloudFront to reduce loading time for viewers in different countries.

---

# Conclusion

AWS provides many cloud services for computing, storage, security, databases, and networking.  
Learning these core services is a great starting point for becoming skilled in cloud computing.
