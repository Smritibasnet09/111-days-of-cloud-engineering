# AWS Learning Topics

## 1. Amazon S3 (Simple Storage Service)

**What it is:** Object storage for files, images, backups, and static websites.

**Key Idea:** Store and retrieve any amount of data from anywhere.

**Example:**

* A company stores training videos and images in S3 for global access.

---

## 2. Amazon EC2 (Elastic Compute Cloud)

**What it is:** Virtual servers in the cloud.

**Key Idea:** You rent a computer in AWS to run applications.

**Example:**

* Hosting a web application on a Linux server running on EC2.

---

## 3. Amazon RDS (Relational Database Service)

**What it is:** Managed SQL database (MySQL, PostgreSQL, etc.).

**Key Idea:** AWS manages backups, patching, and scaling.

**Example:**

* An e-commerce site stores orders and customer data in MySQL RDS.

---

## 4. Amazon VPC (Virtual Private Cloud)

**What it is:** Private network inside AWS.

**Key Idea:** You control IP ranges, subnets, and security.

**Example:**

* A company runs its database in a private subnet so it is not publicly accessible.

---

## 5. Amazon CloudFront

**What it is:** Content Delivery Network (CDN).

**Key Idea:** Speeds up content delivery using edge locations.

**Example:**

* A global website serves images and videos faster to users worldwide using CloudFront.

---

# Quick Memory Trick

* S3 → Store files
* EC2 → Run servers
* RDS → SQL database
* VPC → Private network
* CloudFront → Fast content delivery
