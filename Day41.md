# Important Topics for Exams

## 1. Amazon Redshift

### Description
Amazon Redshift is a fully managed cloud data warehouse service used for analyzing large amounts of data quickly. It is mainly used for business intelligence, analytics, and reporting.

### Key Features
- Fast SQL query performance
- Columnar storage technology
- Scalable data warehouse
- Integration with AWS analytics tools

### Example
A company stores millions of sales records in Redshift to analyze customer purchasing behavior and generate reports.

---

## 2. Amazon EC2

### Description
Amazon EC2 (Elastic Compute Cloud) provides virtual servers in the cloud. Users can launch and manage servers without buying physical hardware.

### Key Features
- Virtual machine hosting
- Flexible instance types
- Scalable infrastructure
- Pay-as-you-go pricing

### Example
A developer hosts a website on an EC2 instance to make it accessible online.

---

## 3. Amazon S3

### Description
Amazon S3 (Simple Storage Service) is an object storage service used for storing files, backups, images, and application data securely.

### Key Features
- Highly durable storage
- Unlimited storage capacity
- Secure access management
- Versioning and backup support

### Example
An organization stores backup files and media content in Amazon S3.

---

## 4. AWS Lambda

### Description
AWS Lambda is a serverless computing service that runs code automatically without managing servers.

### Key Features
- No server management
- Automatic scaling
- Event-driven execution
- Cost-efficient pricing

### Example
When a user uploads an image to S3, Lambda automatically resizes the image.

---

## 5. Amazon RDS

### Description
Amazon RDS (Relational Database Service) is a managed database service that supports MySQL, PostgreSQL, Oracle, and SQL Server.

### Key Features
- Automated backups
- High availability
- Easy database management
- Scalable performance

### Example
A company uses Amazon RDS MySQL to manage customer information for an online application.
