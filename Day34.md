# AWS Database & Analytics Services

# Amazon Redshift

## What is it?
Amazon Redshift is a **data warehouse service** used for:
- big data analytics
- reporting
- running complex SQL queries

## Main Features
- Fast analytics
- Handles huge data
- Uses SQL
- Fully managed by AWS

## Example
Analyze millions of sales records to generate reports.

## Remember
> Redshift = Big Data Analytics

---

# Amazon Aurora

## What is it?
Amazon Aurora is a **high-performance relational database** compatible with:
- MySQL
- PostgreSQL

## Main Features
- Very fast
- High availability
- Automatic backups
- Auto scaling storage

## Example
Used for websites and applications needing fast databases.

## Remember
> Aurora = Powerful Relational Database

---

# Amazon Athena

## What is it?
Amazon Athena is a **serverless query service** used to analyze data directly from Amazon S3 using SQL.

## Main Features
- Serverless
- Queries S3 data directly
- No database setup needed
- Pay per query

## Example
Analyze log files stored in S3.

## Remember
> Athena = Query S3 with SQL

---

| Service | Main Use |
