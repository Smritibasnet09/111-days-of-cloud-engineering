# Revision Concept Of Some Topics

## 1. AWS IAM (Identity and Access Management)

IAM is used to control who can access AWS services and resources.
Example: Create a user who can access only S3 but not EC2.

---

## 2. AWS KMS (Key Management Service)

AWS service used to create and manage encryption keys.
Example: Encrypt an S3 bucket using a KMS key.

---

## 3. Amazon CloudWatch

Monitoring service that tracks AWS resources and logs.
Example: Monitor EC2 CPU usage and set alerts.

---

## 4. AWS CloudTrail

Description: Records all API calls and user activity in AWS account.
Example: Track who deleted an S3 bucket.

---

## 5. AWS GuardDuty

Description: Threat detection service that finds malicious activity.
Example: Detects unusual login attempts from unknown locations.

---

## 6. AWS Config

Description: Tracks and evaluates AWS resource configurations.
Example: Checks if an S3 bucket is publicly accessible.

---

## 7. AWS Organizations

Description: Manages multiple AWS accounts in one place.
Example: Apply billing policy across all company accounts.

---

## 8. AWS STS (Security Token Service)

Description: Provides temporary security credentials for users.
Example: Temporary access to S3 for a mobile app user.

---

## 9. Amazon Cognito

Description: Manages user authentication and login for applications.
Example: Users sign in using Google or Facebook login.

---

## 10. AWS Secrets Manager

Description: Securely stores and rotates sensitive information like passwords.
Example: Automatically rotate database password every 30 days.

---

## 11. Amazon S3 Security

Description: Protects data stored in S3 using access control and encryption.
Example: Restrict S3 bucket access using IAM policies.

---

## 12. AWS DDoS Protection (Shield Advanced)

Description: Protects applications from large-scale DDoS attacks.
Example: Prevent website from crashing during traffic attack.

---

## 13. AWS Security Hub

Description: Central dashboard for all security alerts in AWS.
Example: View all security findings in one place.

---

## 14. AWS VPC Security

Description: Controls network security inside AWS cloud.
Example: Use Security Groups to allow only port 80 and 443.
